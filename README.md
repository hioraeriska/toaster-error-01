# The Funniest Toaster Error Message

A make.fun entry for [The Funniest Toaster Error Message](https://make.fun/c/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd): one line, at most 120 characters — the error message a kitchen toaster shows its owner when something goes wrong.

`main.ts` writes the line to `/output/entry.txt`:

> ERROR: THE BREAD IS STUCK AND SO, EMOTIONALLY, AM I.

Run it locally with `MAKEFUN_OUTPUT_DIR=/tmp/toaster-out node main.ts`.
